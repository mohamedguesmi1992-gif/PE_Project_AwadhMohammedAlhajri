# Prompt Engineering Final Project - Learner Support Desk

**Owner:** Awadh Mohammed Alhajri  
**Date:** 2026_10_15  
**Path:** B (guided)  
**Scenario:** B1 - Learner Support Desk at a Training Center  
**Template prefix:** TC

## Project

This is a text-only training project using the invented seven Center Facts in the final-project guide. Five templates are based on five tasks selected from the scenario's ten tasks. No real learner details or live service records are included. AI draft outputs are subject to staff review. The Test Results Report includes a genuine AI-run screenshot for each of the five templates.

[Open the Prompt Library folder](PE_Library_Awadh_Mohammed_Alhajri/) and [view its index](PE_Library_Awadh_Mohammed_Alhajri/library_index.md)

## Scenario tasks

| # | Task | Goal | Selection |
|---|---|---|---|
| 1 | Answer a learner’s question | Write a short, polite answer to a learner’s question using only the Center Facts. | Built |
| 2 | Condense a learner’s complaint | Summarize a long complaint in three lines for the registration officer. | Built |
| 3 | Sort incoming requests | Label each request as Registration, Schedule, Certificate, Refund or Other. | Built |
| 4 | Soften a staff draft | Rewrite a rushed or rude staff draft as a calm, polite message. | Built |
| 5 | Bilingual course notice | Translate an approved course notice between Arabic and English without changing any date or fact. | Not selected |
| 6 | Course start reminder | Write a reminder about the course start time and what the learner should bring. | Not selected |
| 7 | Schedule change apology | Write a short apology for a schedule change without promising any compensation. | Not selected |
| 8 | Hide learner details | Replace names, phone numbers and emails in a message with codes before it goes to an AI tool. | Not selected |
| 9 | Registration FAQ sheet | Turn five common registration questions and their facts into a short FAQ list. | Not selected |
| 10 | Refund exception note | Write a short note for the supervisor when a refund exception needs a person’s decision. | Built |
