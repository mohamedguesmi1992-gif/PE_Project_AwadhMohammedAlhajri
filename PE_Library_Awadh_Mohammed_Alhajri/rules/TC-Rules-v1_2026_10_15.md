# Training Center Rules · v1

**Owner:** Awadh Mohammed Alhajri  
**Version:** v1  
**Date:** 2026_10_15

| Area | Rule | Yes/no check |
|---|---|---|
| Data | Before entering a learner message in an AI assistant, the desk agent masks any name, contact information, reference number and unnecessary identifying detail. | Was the input masked before use? |
| Verification | Before approving a drafted reply, the reviewer checks every factual claim against the current Training Center Facts and applies all five output-quality criteria. | Was each claim checked and the reply scored? |
| Fairness | Before approving a new template, the owner compares equivalent requests with different wording and checks that the answer, standards and next step remain consistent. | Was a wording-swap comparison checked? |
| Policy | Before using AI for desk work, the agent confirms that the tool is approved by the organization and uses only the current authorized Facts block. | Were the tool and Facts version verified? |
| Human decision | Before any message about eligibility, a refund exception, a payment status or an action is sent, an authorized person reviews the record and decides; the draft never claims an action was taken. | Did an authorized person verify the decision and approve the message? |
